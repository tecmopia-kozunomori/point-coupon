# TECMOPIA デジタルポイントカード SERVER-15

BUILD: `SERVER-15-TUTORIAL-BOOST`

## SERVER-15 追加内容
- 保有0ptで未確認の端末に、4ステップの初回チュートリアルを自動表示
- チュートリアルは「スキップ」可能。ホームの「使い方を見る」から再表示可能
- 貯める → ポイントの受け取り方 → 交換 → クーポン使用場所を実画面上で順番に強調
- 2026/8/12〜2026/8/31、期間中最初の無料チェックインを3ptにブースト
- 過去にチェックイン済みの端末もブースト対象
- ブースト受取後は通常の1日1回1ptに戻る
- 2026/8/12に旧仕様1ptを先に受け取った端末は、再読取で差額2ptを補填

## 既存期間
- ポイント付与：2026年8月31日まで
- ポイント交換・クーポン使用：2026年9月30日まで

## 重要
初回3ptの「1人1回」判定は、現在のシステム仕様上「同じ端末・同じブラウザのポイントカード単位」です。
別端末・別ブラウザまで同一人物として判定するには、会員IDやログイン等の本人識別が別途必要です。
