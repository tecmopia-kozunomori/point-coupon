# TECMOPIA デジタルポイントカード（GASサーバー正本版）

ポイント・クーポン・履歴はGoogle Apps Script側で管理します。
このフォルダの中身をGitHub Pagesのリポジトリ直下へアップロードしてください。

## 主な変更
- ポイント残高をGAS側で保存・判定
- 営業時間10:00〜20:00をGAS側でも判定
- ポイント受取期限、交換・使用期限をGAS側でも判定
- 1日1回チェックインをGAS側で判定
- ポイント交換とクーポン使用をGAS側で処理
- 端末IDに加えて端末秘密鍵を使用
- localStorageは表示用キャッシュのみ
- クーポンバナーは750×250px WebP

Apps Script側の設定は、ZIP直下の「00_最初に読む.txt」を参照してください。
