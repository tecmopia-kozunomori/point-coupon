# TECMOPIA デジタルポイントカード SERVER-04

## 今回の重要変更

- ポイントQRは、ポイントカード内の「カメラでQRコードを読み取る」から読み取った場合だけ有効です。
- スマートフォン標準カメラからQRのURLを直接開いても、案内画面が出るだけでポイントは加算されません。
- QR付きURLはページ起動直後に通常URLへ切り替わります。
- 画像・スクリーンショットからのQR読み取り機能は削除しました。
- サイト内カメラでの読み取り後、GASが5分間有効な認証チケットを発行します。
- ポイント加算成功後、認証チケットは即時無効になります。
- ポイント付与名は「クレーンゲーム500円投入」に統一しました。

## GitHubへアップロードするもの

`01_GitHubへアップロード`フォルダ内のファイルを、GitHubリポジトリのルートへすべて上書きしてください。

## Apps Script

`02_AppsScriptにコピペ/Code.gs`を現在のCode.gsへ全文貼り替え、`setupPointCardSystem`を1回実行してください。その後、ウェブアプリを新バージョンとして再デプロイします。

## 既存QRについて

QRトークンとURLは変更していないため、既存のQRコード自体はそのまま読み取れます。ただし、印刷物に「500円6プレイ」と文字が入っている場合、その表示部分は「クレーンゲーム500円投入」へ差し替えてください。
